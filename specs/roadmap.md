# Roadmap

## Vision

The assistant does not only answer questions about a page. It can also act on
the page for the user and keep an eye on it while the user does something
else.

## Milestones

| Milestone          | Items            | Status |
| ------------------ | ---------------- | ------ |
| Acting on the page | T-001 Agent Mode | Done   |
| Watching the page  | T-002 Watch Mode | Done   |

## Non-goals

- Running when the page is closed or the tab is unloaded.
- Sending page data to a server by default.
